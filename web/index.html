        Using TreeFern

        TreeFern opens cladograms stored as JSON files. Try one of the samples from the menu, or open your own file. Your edits are kept in this browser; use Save or Download to write a .json file.

        Touch

        TapSelect a clade
        Double-tapEdit a clade
        Long-pressClade menu
        Drag / pinchPan / zoom
        Panel buttonsAdd, edit, collapse, cut, paste, delete

        Mouse

        Click / double-clickSelect / edit a clade
        Right-clickClade menu
        HoverShow a clade's info
        Drag a pictureOnto a clade in the tree, the side panel or the Edit box, to add it to the notes
        Drag / wheelPan / zoom (Shift: faster)

        Keyboard

        Ctrl+KCommand palette: every action, by name
        SAdd a sister clade (same keys as below once the box is open)
        A or DAdd daughter clades. In the name box, Enter adds it, Shift+Enter adds it and starts a daughter of it, Ctrl+Tab adds it and starts a sister (in the installed app; in a browser tab use the button), and Tab moves to the info
        E or REdit name and info
        CCollapse or expand
        KColour the clade and everything in it
        Delete / BackspaceDelete the clade and its descendants
        X, then VCut a subtree, paste it under the selected clade
        EscCancel a cut, or clear the selection
        Ctrl+Z / Ctrl+Shift+ZUndo / redo (also Ctrl+Y)
        Arrow keysUp: heaviest daughter. Down: mother. Left/Right: sisters
        F / HomeFocus on the clade / fit the whole tree
        Ctrl+FSearch
        1 2 3 4Standard / Disks / Rectangular cladogram / Circular cladogram layout
        L / Shift+DLabels over or beside nodes / dark mode
        + - [ ] , .Spread, shrink and curl (Standard layout)
        Ctrl+O / Ctrl+SOpen / save a file
        Ctrl+EExport an image of the view or the whole tree
